4. 分阶段落地与评审结论

建议先小步上线
阶段交付验收状态
Phase 1Agent + VM single + 基础 Dashboard节点离线不阻塞页面；30 天可查询Ready
Phase 2告警、版本追踪、模型实例详情离线/高负载可通知，版本可定位Planned
Phase 3VM 集群与长期归档横向扩容不改变 Console APIFuture
当前存储方案：请求明细使用 LiteLLM PostgreSQL SpendLogs，MCP 调用使用本地 SQLite；节点指标使用 VictoriaMetrics 单节点，retention 30 天。
TDengine 评估：它擅长高频设备遥测和超大规模写入，但 Prometheus 生态、PromQL、Grafana/告警集成与现有 exporter 兼容性较弱。当前节点规模下 VM 运维和迁移成本更低；当指标规模达到数十亿样本/月、且需要设备级超高频采集时再评估 TDengine。
