上线判断

可用于常规 Agent

Claude Code、pi、Hermes Agent 与 DeepSeek Harness 均完成真实文件工具任务和精确产物校验；自动工具选择路径稳定。

不可宣称全兼容

任何发送 OpenAI tool_choice=required 或 Anthropic tool_choice={type:any} 的客户端都可能无法调用工具。

保留语义风险

LiteLLM 避免了内联 system 导致的格式错误，但会静默丢弃该消息；需要在网关侧合并到顶层 system，而不是直接删除。
